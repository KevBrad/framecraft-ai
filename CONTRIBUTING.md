# Contributing

Start with a focused issue describing the problem, expected behavior and reproducible steps using permitted sample media. Read the source-availability notice before assuming redistribution or contribution terms. No contributor agreement or permissive application license is invented here.

Keep source originals immutable, preserve saved edits/export history, and distinguish actual analysis from synthetic tests. Do not add unsupported extraction workarounds, private media, secrets, model weights or machine-specific paths. Test an incremental change with the applicable logic/media suite and a frontend production build. Explain limits rather than claiming quality from test counts alone.

Architecture, setup and test instructions are in docs/. Report security concerns using SECURITY.md rather than publishing sensitive material.
