## Actual processing and manual edits

The existing local Whisper pipeline actually recognized the recorded speech. The science project generated four ranked clips and the JFK project generated one clip. The screenshots show real persisted projects, real heuristic scores, real caption data and a real validated H.264 export. All browser checks completed without a page error.

For the demonstrated science clip, the title was manually refined to “Different people need different information,” based on its source passage. A lightbulb pictogram and keyword emphasis were manually selected on the phrase about different priorities. Those are ordinary saved editor choices, not claims that a neural model independently inferred the imagery. The editorial scores and source intervals were not modified.

The public preview `framecraft-real-export-muted.mp4` is the actual rendered clip with its audio stream removed. It contains genuine rendered captions, original vector pictograms and original illustrative graphics. This avoids redistributing a personnel voice recording as product-promotion audio. The private audio-containing render and input files are not publication assets.

The preview is 1080 x 1920 H.264, 37.8 seconds, with no audio stream. Its input graphics are 720 x 1280; the larger output canvas does not restore new source detail. The application displays this source-quality disclosure in its real export preview.
