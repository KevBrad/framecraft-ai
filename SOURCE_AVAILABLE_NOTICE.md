# Source availability and licensing status

No project-wide open-source license has been selected for the original Framecraft code, branding or portfolio materials. Publication makes the source inspectable for portfolio review; it does not introduce an MIT, Apache or other permissive license grant. Default copyright and GitHub platform terms apply. GitHub users can view and fork public repositories under its terms.

Dependencies, fonts and public-domain test materials keep their own licenses/status. See THIRD_PARTY_NOTICES.md and assets/product/PROVENANCE.md. Those third-party terms do not grant a license to the entire Framecraft application. Discuss intended reuse with the maintainer through the confirmed GitHub profile before assuming broader permissions. This document records the project's current status rather than choosing a commercial or open-source license on the owner's behalf.
